# Vanguard Academy — ואנגארד אקדמי

> The first investment-banking training program for decentralized finance.

Vanguard Academy teaches the work an investment bank does — analysis, valuation, M&A, token launches, capital raising, advisory — applied to DAOs and on-chain protocols. Every chapter works from real protocols and real numbers: Lido's income statement, Arbitrum's balance sheet, a full Aave DCF.

## What is in this repository

| Path | Contents |
|---|---|
| [`english-book/`](english-book/SUMMARY.md) | *Investment Banking for DAOs* — the English edition: 6 parts, 20 chapters, about 130,000 words, with case studies, practice exercises and review questions |
| [`docs/SPEC.md`](docs/SPEC.md) | Specification for the learning platform: cohorts, progress tracking, gamification, Hebrew RTL design |
| [`supabase/seed.sql`](supabase/seed.sql) | Starter data for the platform database |

## The book

| Part | Covers |
|---|---|
| I. Foundations | The DAO as an economic entity, DAO financial statements, KPIs, protocol deep dives |
| II. Valuation | Cost of capital in DeFi, protocol DCF (Aave case), relative valuation, advanced methods |
| III. Mergers and acquisitions | Deal landscape, due diligence, structuring, integration |
| IV. Token generation events | TGE design, tokenomics, distribution, launch |
| V. Capital raising | Fundraising execution, treasury management |
| VI. Strategic advisory | Competitive analysis, market positioning, go-to-market |

Start at the [table of contents](english-book/SUMMARY.md). The book is written in GitBook-compatible Markdown and reads directly on GitHub.

## Platform (planned)

The course runs as a dark, Hebrew-first membership site: Next.js on Vercel, Supabase for auth and data, video lessons, and cohort community channels. The full design is in [docs/SPEC.md](docs/SPEC.md); the application code is not in this repository yet.
