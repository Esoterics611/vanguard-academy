# Chapter 9: Transaction Structuring for DAO M&A

Transaction structuring is where the investment banker's analytical work translates into a concrete deal. This chapter covers the mechanics of token exchanges, deal consideration structures, governance integration design, deal protection mechanisms, and fairness opinions — all adapted for the DAO context.

## Chapter Overview

This chapter provides the complete toolkit for structuring DAO M&A transactions:

- **Token exchange mechanics** — exchange ratios, fixed vs. floating, collar mechanisms, and execution
- **Deal consideration structures** — all-token, hybrid, earnouts, and lock-ups
- **Governance integration design** — four models from absorption to dual governance
- **Deal protection mechanisms** — break-up fees, MAC clauses, and competitive defenses
- **Fairness opinions** — methodology and a complete case study

## Key Concepts

{% hint style="info" %}
**The Central Negotiating Point**

The exchange ratio — the number of acquirer tokens received for each target token — is the central negotiating point of any token-swap transaction. It must reflect standalone valuations, synergy sharing, and market price reality checks.
{% endhint %}

By the end of this chapter, you should be able to:

- [ ] Calculate an exchange ratio incorporating standalone valuations and synergy allocation
- [ ] Design a deal consideration structure with appropriate lock-up and earnout provisions
- [ ] Select and justify a governance integration model for a specific transaction
