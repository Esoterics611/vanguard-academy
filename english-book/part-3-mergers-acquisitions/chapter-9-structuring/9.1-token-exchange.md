# 9.1 Token Exchange Mechanics and Deal Structures

The most common DAO M&A structure is a token exchange (or token swap), where the target's token holders receive the acquirer's token at a specified exchange ratio. This is analogous to a stock-for-stock merger in traditional M&A.

{% hint style="info" %}
**Learning Objectives**

After completing this section, you will be able to:
- Calculate an exchange ratio using standalone valuations and synergy allocation
- Compare fixed, floating, and collar exchange ratio mechanisms
- Design smart contract-based token swap execution
- Structure deal consideration including earnouts and lock-up provisions
{% endhint %}

## 9.1.1 Determining the Exchange Ratio

The exchange ratio is the number of acquirer tokens received for each target token. It is the central negotiating point of any token-swap transaction.

### The Exchange Ratio Framework

**Step 1 — Standalone Valuations:** Determine standalone value of both protocols using Part II methodologies (DCF, comparable analysis, precedent transactions).

**Step 2 — Synergy Allocation:** Determine how expected synergy value will be shared. In traditional M&A, the target typically captures 60-80% of synergy value (reflected in the acquisition premium). In DAO M&A, the split is negotiable and should be explicitly agreed upon.

**Step 3 — Calculate the Implied Exchange Ratio:**

```
Exchange Ratio = (Target Value per Token + Target's Synergy Share per Token) / Acquirer Value per Token
```

{% hint style="success" %}
**Worked Example**

- Acquirer standalone value: $2 billion, 100 million tokens = **$20 per token**
- Target standalone value: $300 million, 50 million tokens = **$6 per token**
- Expected synergies: $200 million total
- Synergy split: 60% to target ($120M), 40% to acquirer ($80M)
- Target value including synergy share: ($300M + $120M) / 50M = **$8.40 per target token**
- Exchange ratio: $8.40 / $20.00 = **0.42 acquirer tokens per target token**
{% endhint %}

**Step 4 — Market Price Reality Check:** Compare the implied ratio to current market prices. If target trades at $5 and acquirer at $20, the market-price ratio is 0.25. The proposed ratio of 0.42 represents a **68% premium** to market — within the typical range (25-50%) but on the high end, justifiable if synergies are substantial and well-documented.

**Step 5 — Sensitivity Analysis:** Present the exchange ratio under different valuation and synergy assumptions to demonstrate the negotiation range.

## 9.1.2 Fixed vs. Floating Exchange Ratios

| Mechanism | How It Works | Best When |
|-----------|-------------|-----------|
| **Fixed Ratio** | Set at agreement; does not change | Both sides confident in near-term stability |
| **Floating Ratio** | Adjusts based on token prices at closing | Target wants certainty of dollar value |
| **Collar** | Fixed within a range; adjusts or terminates outside | Volatile crypto markets; balanced protection |

{% hint style="warning" %}
**Recommended for DAO M&A**

A **collar mechanism with a ±30% range** is appropriate given crypto market volatility. Outside this range, either party should have the right to renegotiate or terminate. This balances certainty with protection against extreme price movements.
{% endhint %}

## 9.1.3 Token Swap Execution Mechanisms

### Smart Contract Swap

A purpose-built smart contract that allows target token holders to deposit target tokens and receive acquirer tokens at the specified exchange ratio. This is the most common and cleanest mechanism.

**Key design considerations:**
- **Non-custodial:** Tokens exchanged atomically, no intermediary holding tokens
- **Deadline:** Established swap window (e.g., 90 days)
- **Audited:** Independent audit before deployment
- **Claim mechanism:** Withdrawal function in case of issues

### Governance-Controlled Mint

The acquirer's governance approves minting new tokens to distribute to target holders. Simpler but requires the acquirer's token contract to support governance-controlled minting.

### Wrapper Token

Target tokens deposited into a wrapping contract that issues acquirer tokens in exchange. The wrapper holds target tokens and may eventually burn them.

## 9.2 Deal Consideration Structures

### 9.2.1 All-Token Transactions

The only consideration is the acquirer's governance token.

| | Advantage | Disadvantage |
|-|-----------|--------------|
| | No stablecoin outflow | Dilutive to acquirer holders |
| | Alignment of interests | Exchange ratio negotiation contentious |
| | Simpler structure | Target holders assume acquirer price risk |

### 9.2.2 Token-Plus-Stablecoin Transactions

Hybrid where target holders receive both acquirer tokens and stablecoins. Analogous to cash-plus-stock in traditional M&A.

**Example:** Each target token receives 0.30 acquirer tokens plus $2 USDC. Provides cash certainty while reducing dilution compared to all-token at the same total value.

### 9.2.3 Earnout Structures

A portion of consideration is contingent on post-merger performance. Particularly useful when:
- Target value is uncertain and depends on future performance
- Acquirer and target disagree on valuation
- Acquirer wants to incentivize integration success

**DAO Earnout Mechanics:** Tokens placed in a smart contract that releases upon milestone achievement:

| Milestone Type | Example | Verification |
|---------------|---------|-------------|
| **TVL** | Target product achieves $X TVL within 12 months | On-chain, verifiable via oracle |
| **Revenue** | Product generates $X revenue within 18 months | On-chain protocol data |
| **Users** | Product reaches X daily active users within 12 months | On-chain metrics |
| **Integration** | Smart contract integration completed by specified date | Deployment verification |

{% hint style="success" %}
**Smart Contract Advantage**

Smart contract-based earnouts are superior to traditional earnouts because milestone achievement can be verified on-chain, removing disputes about whether conditions have been met. The contract can automatically release tokens when oracle-verified conditions are satisfied.
{% endhint %}

### 9.2.4 Lock-up and Vesting Provisions

To prevent target holders from immediately selling acquirer tokens:

**Hard Lock-up:** Cannot sell for a specified period (3-12 months). Enforced through smart contract restrictions.

**Graded Vesting:** Tokens vest over time:
```
25% at closing → 25% at 6 months → 25% at 12 months → 25% at 18 months
```

**Differentiated Treatment:**

| Holder Class | Typical Lock-up | Rationale |
|-------------|----------------|-----------|
| Core team | 12-24 months | Retention incentive |
| Large delegates | 6-12 months | Governance stability |
| Retail holders | 3-6 months or none | Lower flight risk, fairness |

---

## Key Takeaways

- The exchange ratio must reflect standalone valuations, synergy allocation, and a market price reality check
- A collar mechanism (±30%) is recommended for crypto M&A given extreme volatility
- Smart contract swaps provide the cleanest, most trustless execution
- Earnout structures resolve valuation disagreements with on-chain verifiable milestones
- Lock-up and vesting provisions prevent selling pressure; differentiated treatment by holder class is standard
- All-token deals align interests but dilute; hybrid structures balance certainty with alignment
