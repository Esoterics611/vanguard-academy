# 4.3 DCF for Token Economies with Complex Mechanics

Many protocols have tokenomic designs that create non-standard cash flow dynamics. This section addresses the most common complexities and how to value them.

## 4.3.1 The Burn Model: Valuing Deflationary Tokens

When protocol revenue is used to buy and burn tokens (reducing total supply), the value accrual to remaining token holders comes through supply reduction rather than direct cash distribution. The analytical framework must capture this mechanism.

### Approach 1: Equivalent Dividend

**Concept:** Treat the burn as economically equivalent to a dividend.

**Logic:** If the protocol uses $100 million of revenue to buy and burn tokens, this is equivalent to distributing $100 million to token holders (who collectively benefit from the supply reduction).

**Application:** The DCF can model burns as if they were dividend distributions.

### Approach 2: Supply-Adjusted Valuation

**Concept:** Model the declining token supply over time and value each remaining token as a larger percentage claim on protocol value.

**Example:**
```
Initial State:
- Protocol value: $1 billion
- Token supply: 100 million tokens
- Per-token value: $10

After 5 Years of Burns (5M tokens/year):
- Protocol value: $1.5 billion (grown)
- Token supply: 75 million tokens (reduced by 25M)
- Per-token value: $20 ($1.5B / 75M)
```

The per-token value increase comes from **both** protocol value growth and supply reduction.

## Case Study: Ethereum Post-Merge (EIP-1559)

Ethereum's implementation of EIP-1559 created a burn mechanism where a portion of transaction fees (the "base fee") is burned, permanently removing ETH from circulation.

### The Mechanism

**Post-Merge Dynamics (September 2022):**
- ETH issuance from staking: approximately 0.5-1.0% annually
- Burns during periods of high activity: can exceed issuance
- Result: ETH can be **net deflationary**

### Modeling ETH's Value

To model ETH's value, project:

1. **Network activity** (transaction volume and gas consumption)
2. **Base fee levels** (a function of network congestion)
3. **Annual burn rate** = base fee × gas consumed
4. **Annual issuance** = staking rewards
5. **Net supply change** = issuance - burns

### Example Calculation

```
Annual Issuance: 600,000 ETH
Annual Burns: 800,000 ETH
Net Supply Reduction: 200,000 ETH (~0.17% of total supply)

Over 10 Years:
Cumulative supply reduction: ~1.7%
```

While modest, this compounds with growing demand for ETH as:
- Collateral in DeFi
- Staking asset
- Unit of account in the ecosystem

{% hint style="info" %}
**Deflationary Impact**

A 1.7% supply reduction combined with growing demand can significantly impact per-token value over time, even if total protocol value remains constant.
{% endhint %}

## 4.3.2 The Vote-Escrow Model: Valuing Time-Locked Governance

The Curve Finance veCRV model introduced a mechanism where token holders lock CRV tokens for up to 4 years to receive:

- ✅ **Boosted governance power** (more voting weight)
- ✅ **Boosted CRV rewards** for liquidity provision
- ✅ **Share of trading fees** (3CRV distributions)
- ✅ **Control over gauge weights** (directing CRV emissions to specific pools)

This creates a multi-layered value proposition where the token's value depends on the lock-up period and the specific benefits derived from each component.

### Valuation Approach for ve Tokens

#### Step 1: Value the Fee Distribution Component

**Example:**
```
Annual trading fees distributed to veCRV holders: $50 million
Total CRV locked: 500 million (average lock 2.5 years)

Annual yield on locked CRV = $50M / 500M = $0.10 per locked CRV
Yield percentage = $0.10 / $1.00 = 10% at $1.00 CRV price
```

#### Step 2: Value the Governance/Gauge Weight Component

**The "Curve Wars":** Control over gauge weights is valuable because it directs CRV emissions (worth hundreds of millions of dollars annually) to specific pools.

**Bribe Market:** Protocols compete to accumulate veCRV to direct emissions toward their liquidity pools. The value of gauge weight control can be estimated by the prices paid for "bribes" (incentive payments to veCRV holders to vote for specific gauges).

**Example:**
```
If total annual bribes amount to $100 million
This additional yield accrues to veCRV holders
Additional yield per locked CRV = $100M / 500M = $0.20
```

#### Step 3: Value the Boost Component

For active liquidity providers, the CRV boost (up to 2.5x rewards) has calculable economic value based on the enhanced yield.

**Calculation:** Compare yield with and without boost to determine the incremental value.

#### Step 4: Apply Illiquidity Discount

A 4-year lock removes the token from circulation, creating an opportunity cost. The analyst must estimate the **illiquidity discount**—typically **15-30%** for a 4-year lock in volatile crypto markets.

### Complete veCRV Valuation Formula

```
Total veCRV Value = PV(Fee Distributions)
                  + PV(Bribe Revenue)
                  + PV(Boost Value)
                  - Illiquidity Discount
```

{% hint style="success" %}
**Generalization**

This component-based valuation approach can be generalized to any ve-model token:
- Balancer's veBAL
- Frax's veFXS
- Other protocols implementing vote-escrow mechanics
{% endhint %}

## 4.3.3 The Staking Model: Valuing Security Provision

Protocols that require staked tokens for economic security (Chainlink, EigenLayer restaking, The Graph) create a different value dynamic. The token's value is anchored by the **security budget**—the amount the protocol is willing to pay for economic security.

### Valuation Framework

```
Security Budget = Protocol Revenue × % Allocated to Security

Required Stake = Security Budget / Required Staking Yield

Token Value = Required Stake / Token Supply
```

### Example Calculation

**Given:**
- Protocol annual revenue: $100 million
- % allocated to security rewards: 30%
- Security budget: $30 million
- Required staking yield (to attract stakers): 10%

**Calculation:**
```
Required Stake = $30M / 0.10 = $300 million
Token Supply = 100 million tokens
Minimum Token Value = $300M / 100M = $3.00 per token
```

### Economic Security Floor

This creates a **floor value** for security-oriented tokens, below which the protocol becomes economically insecure (insufficient staked value to protect against attacks).

{% hint style="info" %}
**Positive Feedback Loop**

The protocol must maintain token value above this floor, creating a positive feedback loop:

**Higher token value** → **More security** → **Handle more value** → **Supports higher token value**
{% endhint %}

### Chainlink Staking Example

**Chainlink's Staking Model (launched 2022-2023):**
- LINK stakers provide economic guarantees for oracle data quality
- Stakers earn rewards from protocol revenue
- Slashing mechanism penalizes incorrect data provision

**Valuation Considerations:**
1. How much value does the oracle network secure?
2. What % of that value is appropriate for the security budget?
3. What staking yield is required to attract sufficient stake?
4. Does the current token price support the required staked value?

## EigenLayer Restaking: Advanced Staking Valuation

**EigenLayer Innovation:** Allows ETH stakers to "restake" their staked ETH to provide security for additional protocols, earning additional rewards.

**Valuation Complexity:**
- Base ETH staking yield (~3-4%)
- Additional restaking yields from multiple protocols
- Increased slashing risk from multiple commitments

**Formula:**
```
Total Expected Restaking Yield = Base Staking Yield
                                + Sum(Protocol Restaking Yields)
                                - Risk-Adjusted Slashing Probability
```

|-----------------|---------------------|-------------------|------------|

## Key Takeaways

✅ Burn models can be valued via equivalent dividend approach or supply-adjusted DCF
✅ Ethereum's EIP-1559 creates net deflationary dynamics during high network activity
✅ ve-models require component-based valuation (fees + bribes + boost - illiquidity discount)
✅ The Curve Wars demonstrate the market value of gauge weight control
✅ Staking models create a security floor for token value
✅ Different tokenomic mechanisms require different analytical frameworks
