# Chapter 4: Discounted Cash Flow Analysis for Protocols and Tokens

This chapter presents the complete DCF methodology for valuing crypto protocols, including detailed case studies and advanced token mechanics.

## Chapter Overview

You will learn how to:

- Define and calculate **Protocol Free Cash Flow (PFCF)**
- Build revenue projection models for different protocol types (DEXs, lending, liquid staking, stablecoins)
- Construct a complete 5-year DCF model with sensitivity and scenario analysis
- Handle dilution from token-based compensation
- Value protocols with complex tokenomics (burn models, vote-escrow, staking)

## Key Framework

```
Protocol Free Cash Flow (PFCF) =
    Gross Protocol Revenue
  - Protocol Operating Expenses
  - Development Capital Expenditure
  - Treasury Reserve Allocation
```
