# Chapter 3: Foundations of Protocol Valuation

Valuation is the intellectual foundation of investment banking. Every advisory engagement—whether M&A, capital raising, strategic repositioning, or restructuring—ultimately depends on the ability to determine what an asset is worth.

## Chapter Overview

This chapter establishes the foundational frameworks for valuing DAOs and crypto protocols. You will learn:

- **Why traditional valuation frameworks need adaptation** (not abandonment) for the crypto context
- **The four layers of protocol value** and how each requires different analytical approaches
- **The critical distinction between protocols and tokens**, and how value accrual mechanisms work
- **How to estimate the cost of capital** for DeFi protocols, including risk-free rates and equity risk premiums
- **Terminal value challenges** unique to crypto protocol valuation

## Key Concepts

{% hint style="info" %}
**Core Principle**

The fundamental insight of discounted cash flow analysis—that an asset's value equals the present value of its future cash flows—is as true for a DeFi protocol as it is for a steel manufacturer. The challenge lies in adaptation, not abandonment.
{% endhint %}

By the end of this chapter, you should be able to:
