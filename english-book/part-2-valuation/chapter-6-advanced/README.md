## Why Advanced Frameworks Matter

Traditional valuation methods (DCF, comps) work well for cash-flow-generating protocols with clear financial profiles. However, many protocols derive significant value from sources that traditional frameworks struggle to capture:

**Network effects:** Layer 1 blockchains, communication protocols, and social networks derive value from user base size and growth dynamics.

**Strategic optionality:** Protocols with unused capabilities (fee switches, multi-chain expansion potential, product extensions) have real options that traditional DCF undervalues.

**Multiple business lines:** Protocols operating several distinct businesses (like MakerDAO with crypto lending, RWA, stablecoin, and SubDAOs) require sum-of-the-parts analysis.

**Future capabilities:** Many protocols are valued on what they *could become* rather than current cash flows—requiring option-based frameworks.

## Framework Selection Guide

| Protocol Type | Primary Method | Secondary Methods |
|--------------|----------------|-------------------|
| Cash-flow protocols (DEX, lending) | DCF, Comps | SOTP if multi-product |
| Infrastructure (L1, L2) | Network models | DCF for fee revenue, Options |
| Early-stage protocols | Comps, Options | DCF with high discount rate |
| Multi-business protocols | SOTP | DCF for each component |
| Optionality-rich protocols | Real options | DCF for base case + options |

{% hint style="info" %}
**Triangulation is Key**

Professional valuations rarely rely on a single method. The most credible analyses present multiple approaches and explain why they converge (or diverge). The football field chart is the standard presentation format.
{% endhint %}
