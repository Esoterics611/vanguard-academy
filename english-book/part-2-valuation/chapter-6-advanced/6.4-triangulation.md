# 6.4 Triangulating Valuation: The Football Field Chart

The DAO investment banker's valuation conclusion should **never rest on a single methodology**. Best practice is to present a "football field" chart showing the value range implied by each methodology.

## 6.4.1 Why Triangulation Matters

### The Problem with Single-Method Valuation

Any single valuation methodology has limitations:

**DCF:**
- Highly sensitive to assumptions
- Terminal value dominates (often 60-80% of total value)
- Growth and discount rates are uncertain

**Comparable Company Analysis:**
- Peer selection is subjective
- Multiple selection requires judgment
- Market multiples reflect current sentiment

**Precedent Transactions:**
- Limited transaction data
- Deals may be outliers
- Market conditions differ

{% hint style="success" %}
**Triangulation Builds Confidence**

When multiple independent methodologies converge on similar values, confidence increases.

When methods diverge significantly, investigation is needed:
- Are assumptions inconsistent?
- Is one method inappropriate for this protocol?
- Does divergence reveal market mispricing?
{% endhint %}

### Professional Standards

Investment banking valuation presentations **always** include multiple methodologies:

1. **DCF analysis** (multiple scenarios)
2. **Comparable company analysis**
3. **Precedent transaction analysis**
4. **52-week trading range** (market reference)
5. **Specialized methods** (network models, real options, SOTP as appropriate)

## 6.4.2 The Football Field Chart

The **football field chart** is the standard visualization for presenting multiple valuation methodologies side by side.

### Why "Football Field"?

The chart resembles an American football field:
- Horizontal bars represent value ranges
- Bars are stacked vertically (one per methodology)
- Hash marks show key reference points
- Current market price shown as vertical line

### Structure

```
                 Valuation Range ($ millions)
Method           |--------[======]--------|
                 Low    Range    High
                       Median

DCF              |----[========]---------|
Comps            |------[====]-----------|
Precedent Tx     |--------[======]-------|
NVT              |----[======]-----------|
Trading Range    |--[==============]-----|
                 |         |             |
                $0      $2,000       $4,000
                         ↑
                   Current Price
```

## 6.4.3 Case Study: Aave Valuation Football Field

Let's construct a complete football field chart for Aave (using the earlier case study data).

### Method 1: DCF Analysis

**Assumptions:**
- Base case growth, 30% cost of equity, 3% terminal growth

**Results:**

| Scenario | Value | Per Token (16M supply) |
|----------|-------|------------------------|
| Bear | $500M | $31 |
| Base | $1,500M | $94 |
| Bull | $3,500M | $219 |

**Football field entry:**
- Low: $500M
- Mid: $1,500M
- High: $3,500M

### Method 2: Comparable Company Analysis

**Peer group P/R multiples:** 15-30x
**Aave revenue:** ~$150M annualized

**Calculation:**

| Multiple | Valuation | Per Token |
|----------|-----------|-----------|
| Low (15x) | $2,250M | $141 |
| Mid (20x) | $3,000M | $188 |
| High (30x) | $4,500M | $281 |

**Football field entry:**
- Low: $2,250M
- Mid: $3,000M
- High: $4,500M

### Method 3: Precedent Transaction Analysis

**Transaction multiples:** 18-25x with control premiums

**Calculation:**

| Scenario | Multiple | Premium | Valuation |
|----------|----------|---------|-----------|
| Low | 15x | 0% | $2,250M |
| Mid | 20x | 20% | $3,600M |
| High | 25x | 30% | $4,875M |

**Football field entry:**
- Low: $2,250M
- Mid: $3,600M
- High: $4,875M

### Method 4: Network Value to Transactions (NVT)

**Approach:** Compare Aave's NVT ratio to peer group

**Benchmark:** Peer lending protocols trade at NVT of 0.015-0.030
**Aave transaction volume:** ~$100B annually

**Implied valuation:**

| NVT | Calculation | Valuation |
|-----|-------------|-----------|
| 0.015 | $100B × 0.015 | $1,500M |
| 0.020 | $100B × 0.020 | $2,000M |
| 0.030 | $100B × 0.030 | $3,000M |

**Football field entry:**
- Low: $1,500M
- Mid: $2,250M
- High: $3,000M

**Note:** NVT methodology is less precise for lending protocols (better for infrastructure); use as supporting reference only.

### Method 5: 52-Week Trading Range

**Historical range:**
- 52-week low: ~$1,200M (~$75/token)
- 52-week high: ~$3,200M (~$200/token)
- Current: ~$2,400M (~$150/token)

**Football field entry:**
- Low: $1,200M
- High: $3,200M
- Midpoint: $2,200M

## 6.4.5 Interpreting Divergence

### Case 1: DCF Below Market Methods

**DCF: $500-1,500M**
**Comps/Precedent: $2,250-4,500M**

**Possible explanations:**
1. DCF assumptions too conservative (growth too low)
2. Terminal value calculation too conservative
3. Discount rate too high
4. Market multiples reflect optionality not captured in DCF
5. Comparables are overvalued (market bubble)

**Investigation needed:**
- Review DCF growth assumptions against peer growth rates
- Check if discount rate is appropriate for protocol risk
- Consider whether real options value should be added to DCF

### Case 2: Comps Above DCF

**DCF: $1,500M**
**Comps: $3,000-4,500M**

**Possible explanations:**
1. Peer multiples reflect growth expectations not in base DCF
2. Market is assigning premium for competitive position
3. Comparables include option value
4. **Potential overvaluation** if fundamentals don't support multiples

### Case 3: Current Price Outside Range

**Valuation range: $2,250-3,600M**
**Current price: $4,500M**

**Implications:**
- Market may be pricing factors not captured in analysis
- Narrative premium (hype cycle)
- Liquidity premium (high trading volume)
- **Potential overvaluation** - consider sell recommendation

{% hint style="warning" %}
**When Methods Disagree**

Divergence is a **signal to investigate**, not ignore:

1. Check assumptions for consistency across methods
2. Consider if one method is inappropriate for this protocol
3. Investigate whether market has information you don't
4. Assess whether divergence represents mispricing opportunity
{% endhint %}

## 6.4.6 Building Your Valuation Opinion

### Step 1: Identify Primary Methods

For most protocols, **two methods are primary:**
1. **DCF** (fundamental intrinsic value)
2. **Comparable company analysis** (market-based validation)

### Step 2: Use Supporting Methods

Additional methods provide validation:
- Precedent transactions (for M&A context)
- NVT/network models (for infrastructure protocols)
- SOTP (for multi-business protocols)
- Trading range (market sentiment check)

### Step 3: Weight the Methods

Assign weights based on reliability:

**Example weighting:**
- DCF: 40%
- Comparable companies: 30%
- Precedent transactions: 15%
- Network models: 10%
- Trading range: 5%

**Weighted average calculation:**
```
Fair Value = (DCF × 0.40) + (Comps × 0.30) + (Precedent × 0.15)
           + (Network × 0.10) + (Trading × 0.05)
```

### Step 4: Establish Fair Value Range

**Conservative approach:**
- Low: 25th percentile across all methods
- Mid: Weighted average
- High: 75th percentile across all methods

**Aggressive approach:**
- Focus on methods most favorable to investment thesis
- Discount methods that don't support thesis

{% hint style="success" %}
**Professional Standards**

In client-facing work:
- Present ALL methodologies transparently
- Explain rationale for weighting
- Show sensitivity to key assumptions
- Don't cherry-pick methods that support desired conclusion
{% endhint %}

## 6.4.7 Investment Recommendation Framework

### Recommendation Based on Current Price vs. Fair Value

**Strong Buy:** Current price <60% of fair value midpoint
**Buy:** Current price 60-85% of fair value
**Hold:** Current price 85-115% of fair value
**Sell:** Current price 115-140% of fair value
**Strong Sell:** Current price >140% of fair value

### Example: Aave Recommendation

**Fair value range:** $2,250-3,600M (midpoint: $2,925M)
**Current price:** $2,400M

**Calculation:**
```
Current / Midpoint = $2,400M / $2,925M = 82%
```

**Recommendation:** **BUY**

**Rationale:** Trading at 18% discount to fair value midpoint, with multiple methodologies supporting upside to $2,900-3,000M range.

**Price target:** $3,000M (12-month)
**Implied upside:** 25%

## Key Takeaways

1. **Never rely on single method** - Professional valuation uses multiple approaches
2. **Football field chart is standard** - Presents all methodologies side-by-side
3. **Convergence builds confidence** - When methods agree, conviction increases
4. **Divergence requires investigation** - Disagreement signals assumptions to review
5. **Weight methods by reliability** - Not all methods equally appropriate for all protocols
6. **Current price vs. fair value** drives recommendation - Systematic framework for buy/sell/hold
