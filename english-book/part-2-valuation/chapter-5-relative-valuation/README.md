# Chapter 5: Relative Valuation — Comparable Analysis for Protocols

Comparable company analysis values a subject asset by reference to the valuation multiples at which similar assets trade. This chapter adapts the traditional "comps" framework for crypto protocols.

## Chapter Overview

You will learn:

- How to construct appropriate **peer groups** for different protocol types
- Which **valuation multiples** are most reliable for DeFi protocols
- How to apply **premiums and discounts** for protocol-specific factors
- How to use **precedent transaction analysis** for DAO M&A scenarios
- Complete **DEX comparable analysis case study**

## Key Multiples for DeFi

| Multiple | Formula | Best Use Case |
|----------|---------|---------------|
| **P/R** | Market Cap / Annual Revenue | Most reliable; works across all protocols |
| **P/E** | Market Cap / Net Income | When expenses are well-documented |
| **EV/R** | Enterprise Value / Revenue | Adjusts for treasury differences |
| **Market Cap / TVL** | FDV / Total Value Locked | Capital efficiency indicator |
| **Revenue / TVL** | Annual Revenue / TVL | Quality metric, not valuation |

## Typical P/R Ranges (2024)

- **Established DEXs:** 10-30x revenue
- **Lending Protocols:** 10-25x revenue
- **Liquid Staking:** 15-40x revenue
- **Oracles/Infrastructure:** 50-100x+ (growth premium)
- **Stablecoin Issuers:** 5-15x revenue (bank-like profile)
