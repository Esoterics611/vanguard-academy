## Chapter 2: Financial Analysis Frameworks

### Revenue Formulas

**DEX Protocol Revenue:**
```
Protocol Revenue = Trading Volume × Fee Rate × Protocol Take Rate
```

**Lending Protocol Revenue:**
```
Protocol Revenue = Active Loans × Average Interest Rate × Protocol Take Rate
```

**Liquid Staking Protocol Revenue:**
```
Protocol Revenue = Total Staked Value × Staking Yield × Commission Rate
```

**Stablecoin Issuer Revenue:**
```
Protocol Revenue = Outstanding Supply × Stability Fee Rate + Liquidation Penalties
```

### Balance Sheet Formulas

**Liquidity-Adjusted Native Token Value:**
```
Adjusted Value = Notional Value × (1 - Liquidity Discount)
```
*Typical liquidity discount: 30-70% depending on token market depth*

### Cash Flow Formulas

**DAO Runway:**
```
Runway (months) = Liquid Treasury Assets / Monthly Net Operating Cash Outflow
```

| Runway | Assessment |
|--------|-----------|
| < 12 months | Existential pressure |
| 12-24 months | Caution zone |
| 24-36 months | Healthy |
| 36+ months | Strong strategic flexibility |

**Operating Cash Flow:**
```
Net Operating Cash Flow = Protocol Revenue - Contributor Compensation - Grants - Infrastructure Costs
```

### KPI Formulas

**Capital Efficiency:**
```
Capital Efficiency = Annual Protocol Revenue / TVL
```

**Token Float:**
```
Float % = Freely Tradable Supply / Total Supply × 100
```

**Governance Participation Rate:**
```
Participation Rate = Tokens Voting / Total Supply × 100
```
