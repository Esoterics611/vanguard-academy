# 2.3 Data Sources and Analytical Tools

{% hint style="info" %}
**Learning Objectives**

After completing this section, you will be able to:
- Navigate the major DeFi data platforms and understand their strengths
- Identify the right data source for each analytical task
- Locate governance, development, and regulatory data for due diligence
- Write basic Dune Analytics queries for protocol analysis
{% endhint %}

{% hint style="warning" %}
**Key Terms**

- **Dune Analytics**: A platform for writing SQL queries against indexed blockchain data — the primary tool for custom on-chain analysis
- **DefiLlama**: An aggregator of TVL, protocol revenue, and standardized DeFi metrics across the ecosystem
- **Token Terminal**: A platform that standardizes protocol financial data into formats familiar to traditional financial analysts
- **Block Explorer**: A tool (like Etherscan) for viewing transaction-level blockchain data, contract code, and token holder data
{% endhint %}

---

The DAO investment banker must be proficient with a core set of data platforms. Here is your analytical toolkit:

## On-Chain Data

### Dune Analytics

The primary platform for custom on-chain queries. Analysts write SQL queries against indexed blockchain data to extract protocol-specific metrics.

{% hint style="success" %}
**Key Point**: Proficiency with Dune is **non-negotiable** for the DAO investment banker. The ability to write custom queries — not just view existing dashboards — separates professional analysts from casual observers.
{% endhint %}

**Best for:** Custom protocol-specific analysis, transaction-level data, metric tracking over time, competitive analysis requiring non-standard comparisons.

### Etherscan and Block Explorers

Provide transaction-level data, contract verification, token holder data, and treasury wallet monitoring. Essential for verifying on-chain claims and tracking specific wallet activity.

**Best for:** Transaction verification, contract code review, token holder distribution, treasury wallet monitoring.

### DefiLlama

Aggregates TVL, protocol revenue, and other standardized metrics across the DeFi ecosystem. The starting point for competitive analysis and market sizing.

**Best for:** Cross-protocol comparison, market overview, TVL tracking, fee and revenue data, chain-level analysis.

### Token Terminal

Standardizes protocol financial data into formats familiar to traditional financial analysts, including P/E ratios, P/S ratios, and revenue multiples.

**Best for:** Traditional-style financial ratios, peer comparison tables, revenue and valuation metrics in familiar formats.

## Off-Chain Data

| Source | Data Type | Why It Matters |
|--------|-----------|----------------|
| **Governance forums** (Discourse, Commonwealth, Snapshot) | Proposal discussions, financial disclosures, strategic debates | Essential qualitative context behind the numbers |
| **GitHub repositories** | Development activity, code quality, technical roadmap | Reveals innovation velocity and technical health |
| **Social channels** (Discord, X/Twitter, Telegram) | Real-time sentiment, community health indicators | Early warning signals for governance crises or momentum shifts |

---

## Legal and Regulatory Sources

Court filings, SEC enforcement actions, CFTC guidance, and international regulatory developments all affect DAO operations and must be monitored.

{% hint style="info" %}
**Landmark Precedent**

**CFTC v. Ooki DAO (2022)** established that DAOs can be held liable as unincorporated associations. This case has implications for every DAO advisory engagement and should be part of any regulatory risk assessment.
{% endhint %}

## Choosing the Right Tool

| Analytical Task | Primary Tool | Secondary Tool |
|----------------|-------------|----------------|
| Protocol revenue over time | DefiLlama | Dune Analytics (for custom breakdowns) |
| Treasury wallet composition | Etherscan | Dune Analytics |
| Peer comparison (P/E, P/S) | Token Terminal | DefiLlama |
| Custom metric tracking | Dune Analytics | — |
| Governance activity | Snapshot / Tally | Governance forum |
| Developer activity | GitHub | Electric Capital Developer Report |
| Regulatory exposure | Court filings, SEC.gov | Legal databases |

{% hint style="warning" %}
**Think About It**

A traditional equity analyst can construct a company's financial profile from a single 10-K filing. A DAO analyst must triangulate 5+ data sources. Is this a weakness of the DAO ecosystem (lack of standardization) or a competitive advantage for skilled analysts (information edge for those who can synthesize)?
{% endhint %}

## Section Summary

- Four on-chain platforms form the analytical core: Dune Analytics, Etherscan, DefiLlama, Token Terminal
- Off-chain data (governance forums, GitHub, social channels) provides essential qualitative context
- Legal and regulatory monitoring is mandatory, not optional
- Dune Analytics proficiency is the single most important technical skill for custom analysis
- Match the tool to the task — each platform has specific strengths
