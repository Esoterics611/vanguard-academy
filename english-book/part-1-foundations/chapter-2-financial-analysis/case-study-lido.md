Lido Finance is the largest liquid staking protocol. Let's construct an approximate income statement from publicly available on-chain data to demonstrate how the framework from Section 2.1 works in practice.

## Revenue Analysis

{% tabs %}
{% tab title="Step 1: Gross Staking Rewards" %}
**Data needed:** Total staked ETH and average staking yield

- Staked ETH: ~$15 billion
- Average annual staking yield: ~3.5%

**Calculation:**

`$15B × 3.5% = $525M in annual gross staking rewards`

These are the total rewards generated by all ETH staked through Lido.
{% endtab %}

{% tab title="Step 2: Protocol Revenue" %}
**Data needed:** Lido's commission rate

Lido charges a **10% commission** on all staking rewards.

`$525M × 10% = $52.5M in annual protocol revenue`

This is Lido's **gross protocol revenue** — the total fees the protocol captures.
{% endtab %}

{% tab title="Step 3: Treasury Revenue" %}
**Data needed:** Revenue split between node operators and DAO

Lido splits its commission **50/50** between node operators and the DAO treasury.

`$52.5M × 50% = $26.25M in annual DAO treasury revenue`

This is Lido's **net protocol revenue** — what actually flows to the DAO.
{% endtab %}
{% endtabs %}

{% hint style="success" %}
**Key Point**: Notice the waterfall: $525M in gross staking rewards becomes $52.5M in protocol revenue, which becomes $26.25M for the DAO treasury. Each step matters for valuation — using the wrong number in a DCF would produce wildly different results.
{% endhint %}

## Operating Income Assessment

{% tabs %}
{% tab title="Optimistic Case" %}
Revenue: $26.25M
Expenses: $25M

**Operating income: +$1.25M** (barely breakeven)
{% endtab %}

{% tab title="Conservative Case" %}
Revenue: $26.25M
Expenses: $35M

**Operating loss: -$8.75M** (burning treasury)
{% endtab %}
{% endtabs %}

Lido's DAO treasury operates **near breakeven to slightly negative** on a cash basis when denominated in stablecoins. However, the treasury holds significant LDO token reserves, and the protocol's strategic value far exceeds its current cash-flow generation.

{% hint style="warning" %}
**Think About It**

This dynamic — a protocol that generates massive gross fees but barely breaks even at the DAO level — is common among growth-stage protocol DAOs. It's analogous to high-growth technology companies that prioritize market share over near-term profitability. How would you determine whether this is a deliberate growth strategy vs. an unsustainable cost structure?
{% endhint %}

## Analytical Takeaway

{% hint style="success" %}
**Key Analytical Takeaway**: When constructing a DAO income statement, the analyst must triangulate multiple data sources: on-chain protocol data (revenue flows), governance proposals (expense approvals), Dune Analytics dashboards (transaction-level detail), and treasury wallet monitoring (actual cash flows). There is no single "annual report" to reference. The analyst's ability to synthesize disparate data sources into a coherent financial picture is a core professional competency.
{% endhint %}
